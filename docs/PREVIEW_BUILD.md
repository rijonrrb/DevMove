# Windows preview build and validation

DevMove v0.1.0 is an **unreleased developer preview**. It has not yet passed a complete clean-Windows migration test. Do not replace independent backups with this tool.

## Prepare a development workstation

- Windows 10/11 with WebView2 installed.
- Node.js/npm, Rust toolchain (rustup), and MSVC C++ build tools.
- Clone this repository and change to the desktop directory.

For local development: run npm ci, npm run lint, npm run build, and npx tauri dev. The browser-only Vite view is not connected to Windows-native APIs.

For a Windows installer, run npx tauri build --bundles nsis. The resulting EXE is created under the desktop/src-tauri/target/release/bundle/nsis directory. The standalone EXE is placed under desktop/src-tauri/target/release.

## Verification

The project validates React/TypeScript build, lint, Rust checks and unit tests in .github/workflows/windows-ci.yml. Local smoke testing also includes opening the Windows-native application and checking its responsiveness.

The installer generated by a local development machine is **unsigned** unless code signing is configured. Windows SmartScreen or organization policy may warn or block unsigned applications. An official public release should use code signing and release artifacts produced through a controlled build pipeline.

## Current capability

- Native Windows app and driver inventory.
- Application-by-application selection and WinGet package metadata export.
- Selected ZIP backup with SHA-256 manifest and verification, including explicitly chosen project folders with sensitive/generated-file exclusions.
- Staging extraction to a new folder (does not directly apply settings).
- Read-only restore plan from a verified ZIP: recorded WinGet package IDs, manual reinstall list, and archive warnings.
- Read-only PnP diagnostics, export of eligible third-party driver packages.

## Not ready for Windows formatting

- Automatic software reinstallation from a backup.
- XAMPP SQL/database restore, automatic project configuration restore, and excluded credential migration.
- Google Drive OAuth, private archive encryption, resumable cloud upload.
- Automatic compatible driver update and restore-point creation.
- Full end-to-end restore validation and documented downgrade handling.

Before reinstalling Windows, independently save essential data to another physical drive, export databases, enable Chrome/VS Code account sync, and test a small restore. A checksum-valid archive is not by itself proof that a full system migration will succeed.

## Project artifacts

Build artifacts such as .exe, .msi, archives, and credentials should not be committed to Git. The public repository contains the source, build configuration, validation workflow and documentation.
